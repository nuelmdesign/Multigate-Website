# Core value objects (static)

Five blue wireframe objects for the About page core value cards, in the same line style as the use-case wireframes (Corporates, Financiers, Banks, Financial Institutions).

| Value | Object | What it says | File |
| --- | --- | --- | --- |
| Customer Obsession | Magnifying lens | Understanding and attention | `customer-obsession-magnifier` |
| Excellence | Pocket watch | Precision and mastery | `excellence-watch` |
| Agility & Innovation | Gyroscope | Adaptability and movement | `agility-innovation-gyroscope` |
| Trust & Accountability | Anchor | Stability and dependability | `trust-accountability-anchor` |
| Empowerment & Ownership | Skeleton key | Agency and responsibility | `empowerment-ownership-skeleton-key` |

## Files

- `*.svg` — 600 x 600, transparent background, vector. Drag into Figma. Single stroke colour `#1362F5`, 1.5 px, round caps. Back lines are fainter than front lines (six opacity levels, grouped as `depth-1` to `depth-6`), which gives the depth you see in the use-case wireframes.
- `*.png` — 1200 x 1200, transparent background, for quick previews or tools that do not take SVG.
- `core-values-preview-dark.png` and `core-values-preview-light.png` — all five side by side on a navy card and on a light card, for review only.

## Using them

- The strokes are plain `#1362F5`, so on a light card they read as in the light preview and on the navy card as in the dark preview. To recolour, select the group in Figma and change the stroke.
- Each object is drawn from a real 3D model, so a different angle or pose can be exported on request.
- Static only for now. Animated versions (rotating, like the use-case loops) can follow.

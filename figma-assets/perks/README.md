# Perk objects (static)

Eight small blue wireframe objects for the careers / "reasons to work with us" section, in the same line style as the use-case and core-value wireframes. They are placeholders for the layout: swap or add objects once the real list of perks is confirmed.

| Perk (placeholder) | Object | File |
| --- | --- | --- |
| Health cover | Medical cross | `health-cover-cross` |
| Pay and rewards | Coin | `pay-rewards-coin` |
| Retirement | Hourglass | `retirement-hourglass` |
| Learning | Open book | `learning-book` |
| Equipment | Laptop | `equipment-laptop` |
| Time off | Desk calendar | `time-off-calendar` |
| Flexible work | House | `flexible-work-house` |
| Team time | Coffee cup | `team-time-coffee-cup` |

## Files

- `*.svg`: 240 x 240, transparent, vector. Single stroke colour `#1362F5`, 3 px, round caps. Back lines are fainter than front lines. Drawn with a sparser mesh than the core-value set so they stay clean at 72 px.
- `*.png`: 480 x 480, transparent.
- `perks-preview-large.png`: all eight at a larger size, for review.
- `perks-preview-actual-size.png`: all eight at 72 px beside placeholder text, as they would sit in the layout.

Static only. Animated versions can follow.
